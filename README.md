# JIA-BOLG

一个轻量、极简的静态个人站点，部署在 GitHub Pages。

## 功能

- 随机短文阅读
- IP 信息查询
- 响应式布局
- GitHub Pages 自动部署

## 技术

- HTML
- CSS
- JavaScript
- GitHub Actions
- GitHub Pages

## 目录

- `index.html`：首页
- `ip.html`：IP 查询页
- `assets/`：静态资源
- `.github/workflows/static.yml`：Pages 自动部署工作流

## 部署

推送到 `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages。
